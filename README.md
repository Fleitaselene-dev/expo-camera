# En el mismo proyecto utilizado en el TPN°6, y tomando como referencia la documentación oficial de Expo Camera:
https://docs.expo.dev/versions/latest/sdk/camera/

Deberán:

1. Crear una nueva rama en su repositorio para trabajar este práctico.
2. Agregar una nueva sección dentro del panel de administración, destinada a la gestión de productos (o elementos, si prefieren nombrarlos de otra manera).
3. Implementar la lectura de códigos QR o de barras utilizando la funcionalidad de Barcode Scanner integrada en expo-camera.
4. Permitir en esta sección las siguientes operaciones sobre los productos:
Agregar un producto a través del escaneo del código.
Modificar un producto previamente cargado.
Eliminar un producto existente.
5. Incorporar loaders o alertas que informen al usuario en los siguientes casos:
Cuando la operación se realiza con éxito.
Cuando ocurre un error (por ejemplo, al escanear o guardar datos).

Importante: No es necesario crear un servidor ni una base de datos para realizar la tarea. Los datos podrán almacenarse en variables locales (hardcodeadas) dentro del proyecto.
